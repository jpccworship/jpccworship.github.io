# JPCC Worship People

Halaman web JPCC Worship (GitHub Pages):

- `/jadwalpelayanan/` — Jadwal Pelayanan (cari jadwal, blockout, izin / tukar)
- `/evaluasi-internal/` — Evaluasi Pelayanan (internal tim)
- `/evaluasi-eksternal/` — Masukan Ibadah (eksternal)

Data dibaca dan disimpan ke Google Sheet admin lewat web app Apps Script (`assets/jpcc.js`, variabel `API`).
Jangan ubah isi halaman langsung di sini: halaman dibuat ulang dari template di Apps Script.
